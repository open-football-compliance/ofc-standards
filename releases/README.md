# OFC Standards — Releases

Esta pasta contém versões publicadas e identificáveis das especificações e documentos institucionais do Open Football Compliance.

## Release structure

Cada release deve possuir um identificador de versão e conter os artefatos correspondentes.

Exemplo:

```text
releases/
└── v0.1.0/
    ├── ofe-scope.pdf
    ├── financial-indicators-dictionary.pdf
    ├── bordero-data-standard.pdf
    └── release-notes.md
```

## Release policy

- Releases devem corresponder a versões identificáveis dos documentos-fonte.
- PDFs publicados devem ser gerados a partir das versões editáveis armazenadas em `docs/`.
- Alterações posteriores devem gerar nova versão ou revisão formal.
- Releases anteriores devem ser preservados para garantir rastreabilidade.
- Cada release deve conter notas com as alterações e limitações conhecidas.
