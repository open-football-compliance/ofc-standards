# Contributing to OFC Standards

Obrigado pelo interesse em contribuir com os padrões do Open Football Compliance (OFC).

Este repositório mantém especificações, metodologias, contratos de dados e documentos de referência para promover transparência, consistência e interoperabilidade no futebol.

## 1. Formas de contribuição

São bem-vindas contribuições relacionadas a:

- Correções e esclarecimentos em documentos existentes.
- Propostas de novos padrões e indicadores.
- Melhorias em modelos de dados, taxonomias e JSON Schemas.
- Exemplos baseados em documentos oficiais.
- Identificação de inconsistências e problemas de comparabilidade.
- Sugestões de evolução das metodologias.

## 2. Processo de contribuição

O processo recomendado é:

1. Verificar se já existe uma Issue relacionada ao assunto.
2. Criar uma Issue descrevendo o problema ou a proposta.
3. Aguardar discussão e alinhamento sobre a alteração.
4. Criar uma branch específica para a contribuição.
5. Submeter um Pull Request com as alterações.
6. Aguardar revisão e aprovação dos responsáveis pelo padrão.

## 3. Diretrizes para documentos

Toda especificação deve informar:

- Nome e identificador do documento.
- Versão.
- Status de publicação.
- Objetivo e escopo.
- Definições e terminologia.
- Regras aplicáveis.
- Exemplos, quando pertinentes.
- Histórico de alterações.

As alterações devem preservar a rastreabilidade das decisões e evitar mudanças silenciosas de significado.

## 4. Diretrizes para padrões de dados

Alterações em schemas, catálogos e modelos de dados devem:

- Preservar compatibilidade sempre que possível.
- Documentar campos obrigatórios e opcionais.
- Definir tipos, unidades e restrições.
- Explicar regras de validação.
- Incluir exemplos válidos.
- Documentar mudanças incompatíveis.

## 5. Pull Requests

Cada Pull Request deve apresentar:

- Resumo da alteração.
- Motivação e problema tratado.
- Documentos e versões afetados.
- Impactos sobre compatibilidade.
- Exemplos ou testes, quando aplicáveis.

## 6. Revisão e aprovação

A aprovação de alterações normativas cabe aos responsáveis institucionais designados pelo OFC.

Contribuições externas podem ser incorporadas após análise técnica e metodológica.

A abertura de um Pull Request não implica aprovação automática de uma proposta.
